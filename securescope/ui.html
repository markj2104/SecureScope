A focused configuration review

Secure Scope sends ordinary GET requests to one URL, follows up to five redirects (which may reach other hosts), and reads at most 512 KiB of response content. Only the final response’s headers, cookies, and HTML are analyzed.

  • Checks HTTPS, certificate trust and expiry, HSTS, MIME sniffing protection, HTML header policies, cookie attributes, and HTTP resource/form references.
  • No crawling, login attempts, JavaScript execution, port scanning, CVE detection, or exploit payloads.
  • CSP analysis is heuristic. Missing protections can be intentional. Cookie purpose is unknown. Error-page findings may differ from application pages.
  • Only the negotiated TLS connection is observed, not every protocol or cipher the server supports. Verification uses Python’s local trust store. Proxy environment settings are not used.
  • Reports redact query strings and Set-Cookie values. Paths and other response headers may still contain sensitive information; review before sharing.
  • No telemetry or remote assets. The GUI server listens only on loopback and requires a per-launch session token. Use Quit app to stop the server; closing a browser tab alone does not stop it.
  • Cancellation waits for the current network operation. DNS resolution can take longer than the socket timeout on some systems.
